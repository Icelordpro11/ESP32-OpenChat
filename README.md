# ESP32 Open Chat

Local offline chat system hosted directly on ESP32 using a captive portal.

## Usage

1. Flash ESP32
2. Connect to:
   Free Open Chat WIFI
3. Open:
   http://192.168.4.1

## Tech

- ESP32
- Arduino Framework
- PlatformIO
- WebServer
- DNSServer

## Features

- ESP32 Access Point
- Captive Portal
- Embedded Web Chat
- Mobile Friendly UI
- DNS Redirect
- Offline Communication
